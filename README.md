# ai-ux.io

One-page site for Vijay Kandhalu — UX lead with AI teammates. Built with Next.js and [NVIDIA Elements](https://nvidia.github.io/elements/).

## Develop

```bash
npm install
npm run dev
```

## Verify

```bash
npm run lint
npm run build
```

Content lives in `content/*.ts` and drives the page, JSON-LD, and `llms.txt`.
